# Address Book Project

## 📖 Description
The Address Book is a simple C program designed to store and manage contact information.  
It allows users to add, search, edit, and delete contacts such as names, phone numbers, and email addresses.

## ✨ Features
- Add new contacts
- View all saved contacts
- Search contacts by name or number
- Edit existing contact details
- Delete outdated contacts

## 🛠️ Technologies Used
- C programming language
- Structures (`struct`) for contact details
- Arrays for storing multiple contacts
- File handling for saving and loading data

## 🚀 How to Run
1. Clone the repository:
   gcc addressbook.c -o addressbook
